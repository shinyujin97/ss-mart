# 비즈니스 규칙 위반 검사

코드베이스 전체를 스캔하여 다음 위반 사례를 검출합니다.

## 검사 항목

### 1. 자수 시스템

```
🔴 클라이언트 사이드 가격 계산만으로 결제 진행
🔴 저작권 검증 없이 시안 생성
🔴 시안 상태 머신 무시 (ALLOWED_TRANSITIONS 우회)
🔴 자수 추가 상품 단순 변심 환불 자동 처리
```

### 2. 단체주문

```
🔴 100벌 미만에 단체할인 적용
🔴 사업자 회원이 아닌데 세금계산서 발행
🔴 견적 유효기간 만료 처리 누락
🔴 매니저 배정 없이 견적 자동 발송
```

### 3. 결제 / 주문

```
🔴 클라이언트 가격으로 PG 호출
🔴 카드 정보 자체 저장
🔴 트랜잭션 없는 재고 차감
🔴 SELECT FOR UPDATE 없는 동시성 처리
🔴 PG 콜백 서명 검증 누락
```

### 4. 회원 / 인증

```
🔴 비밀번호 평문 저장
🔴 사업자번호 평문 저장
🔴 권한 체크 없는 API 엔드포인트
🔴 타 회원 데이터 접근 가능
```

### 5. 상품 / 카테고리

```
🟠 KCs 인증 필수 카테고리에 인증 정보 없음 (안전화/안전모/마스크)
🟠 카테고리 슬러그 변경 (URL 끊김)
🟠 N+1 쿼리
```

## 검사 절차

1. `Grep` 으로 위험 패턴 전체 검색
2. 발견된 케이스 `Read` 로 상세 검토
3. `docs/domain/business-rules.md` 와 대조
4. 위반 사례 우선순위 별로 정리
