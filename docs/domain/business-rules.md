# 비즈니스 도메인 규칙 (Business Rules)

> ⚠️ **이 문서가 코드보다 우선합니다.** 기술적 편의를 위해 비즈니스 규칙을 임의로 변경하지 마세요.
> 모든 규칙 변경은 사장님 / 사업 담당자와 합의 후 이 문서를 먼저 업데이트.

## 1. 자수 / 마킹 (Embroidery / Marking)

### 1.1 자수 종류 (7가지)

| 코드 | 한글명 | 설명 | 평균 단가 | 단체할인 |
|------|--------|------|----------|---------|
| `COMPUTER` | 컴퓨터 자수 | 가장 일반적, 실로 한 땀 한 땀 박음 | 5,000~15,000원 | 100벌+ 무료 |
| `PATCH` | 패치 자수 | 별도 천에 자수 후 봉제 | 8,000~20,000원 | 100벌+ 무료 |
| `APPLIQUE` | 아플리케 자수 | 천을 잘라 붙여 입체감 | 12,000~25,000원 | 협의 |
| `REAL_PATCH` | 실사 패치 | 사진 / 일러스트 그대로 | 15,000~30,000원 | 협의 |
| `VELCRO` | 벨크로 패치 | 탈부착 가능, 군 / 보안용 | 18,000~35,000원 | 협의 |
| `CHARACTER` | 캐릭터 디자인 | 오리지널 캐릭터 디자인 + 자수 | 20,000원~ | 협의 |
| `SILK_PRINT` | 실크 인쇄 | 잉크 인쇄, 자수 아님 | 3,000~10,000원 | 100벌+ 무료 |

### 1.2 자수 위치

```typescript
type EmbroideryPosition =
  | 'LEFT_CHEST'      // 왼가슴 (가장 일반적)
  | 'RIGHT_CHEST'     // 오른가슴
  | 'BACK_CENTER'     // 등판 중앙
  | 'BACK_TOP'        // 등 상단
  | 'LEFT_SLEEVE'     // 왼팔
  | 'RIGHT_SLEEVE'    // 오른팔
  | 'MULTIPLE'        // 여러 곳 (상담 필요)
```

### 1.3 자수 크기

| 크기 코드 | 실측 (cm) | 가격 가산 |
|----------|-----------|----------|
| `SMALL` | 5×5 | 기본 |
| `MEDIUM` | 8×8 | +30% |
| `LARGE` | 10×10 | +60% |
| `XLARGE` | 15×15 | +120% |
| `XXLARGE` | 20×20 | +200% (등판 대형) |

### 1.4 가격 계산 공식

```typescript
// 자수 단가 계산 (예시)
function calculateEmbroideryPrice(
  type: EmbroideryType,
  size: EmbroiderySize,
  positions: EmbroideryPosition[],
  quantity: number
): number {
  const basePrice = EMBROIDERY_BASE_PRICES[type];
  const sizeMultiplier = SIZE_MULTIPLIERS[size];
  const positionCount = positions.length;

  // 단체주문 할인 (100벌+ 자수 무료, 단 SILK_PRINT/COMPUTER/PATCH만)
  if (quantity >= 100 && BULK_FREE_TYPES.includes(type)) {
    return 0;
  }

  return Math.round(
    basePrice * sizeMultiplier * positionCount * quantity
  );
}
```

### 1.7 저작권 정책 (★ 중요)

**절대 작업 불가**:
- ❌ 디즈니, 마블, DC 등 영화 / 애니 IP
- ❌ 닌텐도, 포켓몬, 짱구 등 게임 / 만화 IP
- ❌ 스포츠 팀 공식 로고 (NBA, MLB 등)
- ❌ 명품 브랜드 로고 (루이비통, 구찌 등)
- ❌ 정부 기관 / 공공 로고 (무단 사용)
- ❌ 정치 / 종교 차별 / 폭력 표현

**작업 가능**:
- ✅ 고객사 자체 로고 / 캐릭터 (사업자 증빙 시)
- ✅ 우리 디자이너가 만든 오리지널 디자인
- ✅ 텍스트 (회사명 / 슬로건 / 직책)
- ✅ 일반 모티브 (별, 동물 실루엣 등 저작권 없는 것)

**저작권 검증 프로세스**:
1. 시안 업로드 시 자동 차단 키워드 (예: "디즈니", "마블")
2. 디자이너 1차 검수 (시안 확정 전)
3. 의심 시 사장님 / 매니저 확인

### 1.8 자수 추가 상품 환불 정책

```
✅ 환불 가능
   - 제품 자체 불량 (실밥, 박음질 불량)
   - 자수 작업 불량 (오타, 잘못된 위치)
   - 오배송 (다른 디자인)

❌ 환불 불가 (전자상거래법 제17조 맞춤 제작 조항)
   - 단순 변심
   - 시안 확정 후 디자인 변경 요청
   - 고객 본인 잘못된 시안 입력 (오타)
```

## 2. 단체주문 (Bulk Order / B2B)

### 2.1 단체주문 자격

```
✅ 단체주문 자격
   - 동일 상품 100벌 이상
   - OR 자수 / 마킹 추가 50벌 이상
   - OR 견적가 500만원 이상
```

### 2.2 단체할인 정책

| 수량 | 상품 할인 | 자수 / 마킹 |
|------|----------|------------|
| 100~199벌 | 20% | 무료 (기본 자수) |
| 200~499벌 | 25% | 무료 |
| 500벌+ | 30% | 무료 + 추가 협의 |
| 1,000벌+ | 협의 | 무료 + 캐릭터 디자인 무료 |

### 2.3 견적 진행 단계

```
[견적 요청]
   사용자가 폼 작성 → DB 저장
       ↓
[매니저 배정] (영업시간 내 2시간)
   상태: ASSIGNED
       ↓
[견적서 작성] (1~2영업일)
   PDF 견적서 + 카톡 전송
   상태: QUOTED
       ↓
[고객 확인]
   수락 / 거절 / 협의
       ↓
[자수 시안 제작] (확정 시, 2~3일)
   상태: DESIGN_IN_PROGRESS
       ↓
[계약 / 결제]
   세금계산서 발행 가능
   상태: CONTRACT_SIGNED
       ↓
[제작 시작]
   상태: IN_PRODUCTION
       ↓
[분할 납품 가능]
   부분 출고 시 IN_DELIVERY
       ↓
[완료]
   상태: COMPLETED
```

### 2.4 견적서 필수 항목

```yaml
QuoteResponse:
  - 견적번호 (예: SS-Q-2026-04-001)
  - 회사명 / 담당자
  - 견적 유효기간 (기본 14일)
  - 상품 내역
    - 카테고리 / 브랜드 / 모델
    - 사이즈별 수량
    - 단가 / 총액
  - 자수 / 마킹 옵션 (있는 경우)
    - 종류 / 위치 / 크기
    - 시안 작업 비용
    - 자수 단가
  - 부가가치세 (10%)
  - 운송비 (단체주문 무료)
  - 결제 조건
  - 납품 일정
  - 담당 매니저 연락처
```

### 2.5 결제 조건 (B2B)

| 결제 방식 | 조건 |
|----------|------|
| 일시 결제 | 계약 시 100% |
| 분할 결제 (작은 규모) | 계약 시 50% + 납품 시 50% |
| 분할 결제 (대규모) | 계약 시 30% + 납품 시 70% |
| **신용 거래** | 기업 신용 등급 협의 (기존 거래처) |
| 세금계산서 | 자동 발행 (사업자 회원) |

## 3. 회원 시스템

### 3.1 회원 종류

```typescript
enum MemberType {
  INDIVIDUAL    = 'INDIVIDUAL',     // 개인 회원
  BUSINESS      = 'BUSINESS',       // 법인 / 개인사업자
  SUSPENDED     = 'SUSPENDED',      // 정지
  WITHDRAWN     = 'WITHDRAWN',      // 탈퇴
}
```

### 3.2 회원 등급 (포인트 / 누적 구매액 기준)

| 등급 | 누적 구매액 | 적립률 | 추가 혜택 |
|------|------------|-------|----------|
| FAMILY | 0~ | 1% | 기본 |
| FRIEND | 30만원+ | 1.5% | 생일 5,000원 |
| **VIP** | 100만원+ | 2% | 무료 자수 시안 무제한 |
| **VVIP** | 500만원+ | 3% | 전담 매니저, 한정 상품 |

법인 회원은 별도 등급 (단체주문 기준).

### 3.3 가입 혜택 (★ 시안 일관성)

신규 가입 즉시:
- ✅ **2,000P** 즉시 적립
- ✅ **10% 첫 구매 쿠폰** (최대 5만원)
- ✅ **무료 자수 시안 1회**
- ✅ **생일 축하 쿠폰** 5,000원 (매년)
- ✅ **무료 배송** (전 상품)

### 3.4 적립금 정책

```
- 사용 가능 단위: 1,000P 이상
- 사용 한도: 결제 금액의 50%
- 유효 기간: 적립일로부터 1년
- 적립 시점: 구매 확정 (배송 완료 후 7일)
- 자수 추가 상품도 적립 대상
- 단체주문은 별도 협의
```

### 3.5 사업자 회원 (★ B2B)

추가 가입 정보:
- 회사명 (필수)
- 사업자등록번호 (필수, 검증 API 연동)
- 대표자명
- 업종 / 업태
- 세금계산서 발행 이메일

추가 혜택:
- 자동 세금계산서 발행
- 신용 거래 가능 (협의)
- 전담 매니저 (VIP 전환 시)
- 단체주문 견적 자동 우선순위

## 5. 결제 / 주문

### 5.1 결제 수단

```
1. 신용카드 / 체크카드
   - 11개 카드사 지원
   - 일시불 / 2~12개월 할부
   - 무이자 할부 이벤트 별도

2. 간편결제
   - 카카오페이 / 네이버페이 / 토스페이
   - 페이코 / 삼성페이

3. 계좌이체
   - 실시간 계좌이체

4. 무통장입금
   - 입금 확인 후 출고 (지연 가능)
   - 7일 미입금 시 자동 취소

5. ★ 법인 / 세금계산서 (B2B)
   - 사업자 회원 전용
   - 계약서 / 세금계산서 자동 발행
   - 신용 거래 협의
```

### 5.2 주문 상태 머신

```
[일반 상품]
PENDING → PAID → SHIPPING → DELIVERED → CONFIRMED
                                              ↓
                                      (구매확정 7일 후 자동)

[자수 추가 상품]
PENDING → PAID → DESIGN_REVIEW → DESIGN_CONFIRMED
                                        ↓
                                IN_PRODUCTION → SHIPPING → DELIVERED → CONFIRMED

[취소 / 환불]
PAID → CANCEL_REQUESTED → REFUNDED  (자수 시작 전 가능)
PAID → REFUND_REJECTED               (자수 작업 진행 중)
```

### 5.3 환불 정책

```
✅ 무료 환불 (자수 없는 일반 상품)
   - 수령 후 7일 이내
   - 단순 변심 OK
   - 무료 반품

⚠️ 조건부 환불 (자수 추가 상품)
   - 시안 확정 전: 자수 비용 환불 가능
   - 시안 확정 후: 환불 불가 (제품 불량 제외)
   - 자수 작업 시작 후: 환불 불가

❌ 환불 불가
   - 위생 상품 사용 후 (속옷류)
   - 고객 책임 파손
   - 30일 경과
```

### 5.4 배송 정책

```
[일반 배송] (무료)
- 평일 14시 이전 결제 시 당일 출고
- 1~2일 내 도착
- 제주 / 도서산간 추가비 없음

[새벽 배송] (+3,000원)
- 서울 / 경기 일부 지역만
- 다음날 새벽 7시 이전 도착
- 자수 추가 상품 불가

[단체주문 배송]
- 7~14일 (수량에 따라)
- 분할 배송 가능 (협의)
- 무료 (수량 무관)
```
