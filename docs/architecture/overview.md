# 시스템 아키텍처 개요

> 전체 시스템 구조를 한눈에 파악하는 문서. 새로 합류한 개발자가 가장 먼저 읽어야 함.

## 1. 시스템 전체 구조

```
┌────────────────────────────────────────────────────────────────────┐
│                         사용자 (Browser / Mobile)                   │
└────────────────────────────────────────────────────────────────────┘
                                  │
                                  │ HTTPS
                                  ▼
┌────────────────────────────────────────────────────────────────────┐
│                          CDN / Edge Cache                            │
│              (이미지, 정적 자산, 페이지 HTML 캐싱)                    │
└────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌────────────────────────────────────────────────────────────────────┐
│                        Next.js Application                          │
│  ┌───────────────────┐   ┌───────────────────┐   ┌──────────────┐ │
```

## 2. 핵심 도메인 영역

이커머스 + 자수 / 단체주문이라는 특수성 때문에 일반 쇼핑몰보다 도메인이 복잡합니다.

### 2.1 일반 이커머스 도메인 (필수)

```
회원 (Member)
├── 일반 회원
└── 법인 / 사업자 회원
    └── 사업자등록번호 / 세금계산서

상품 (Product)
├── 카테고리 (작업복/안전화/안전용품/F&B/의료)
├── 브랜드 (PIOZEN, K2 SAFETY, CARHARTT 등 80+)
├── 옵션 (색상, 사이즈)
└── 인증 정보 (KCs, KS, 방염, 정전기방지)

주문 (Order)
├── 일반 주문
├── 자수 추가 주문 ★ (별도 상태 머신)
└── 단체 주문 ★ (B2B, 견적 → 계약 → 제작)

결제 (Payment)
├── 카드 / 간편결제 / 계좌이체 / 무통장
└── 세금계산서 발행 (법인)

배송 (Shipping)
└── 일반 배송 (무료) / 새벽 배송 (+3,000원)

리뷰 (Review)
├── 별점 + 텍스트
├── 사이즈/색상/자수 추가 태그
└── 사진 첨부
```

### 2.2 자수 시스템 (★ 차별화 핵심)

```
자수 시안 (Embroidery Design)
├── 시뮬레이터 시안 (DIY)
│   └── 주문 전 결제 가능 시안
├── 디자이너 시안 (전문가 작업)
│   └── 결제 후 카톡으로 시안 전송
└── 시안 보관함 (마이페이지)
    └── DRAFT / 작업중 / 확정 / 작업완료

자수 옵션 (Embroidery Option)
├── 자수 종류 (7가지)
│   ├── 컴퓨터 자수
│   ├── 패치 자수
│   ├── 아플리케 자수
│   ├── 실사 패치
│   ├── 벨크로 패치
│   ├── 캐릭터 디자인
│   └── 실크 인쇄
├── 자수 위치 (왼가슴/오른가슴/등판/팔)
├── 자수 크기 (5×5, 8×8, 10×10, 15×15cm)
└── 자수 가격 (종류 × 크기 × 위치 수)

자수 작업 상태 머신
   결제완료 → 시안검토 → 시안확정 → 작업중 → 검수 → 완료
                  ↓
              수정요청 (무료, 무제한)
```

### 2.3 단체주문 (★ B2B 핵심)

```
견적 요청 (Quote Request)
├── 회사 정보 (사업자번호, 담당자)
├── 카테고리 (다중 선택)
├── 사이즈별 수량 (S/M/L/XL/2XL)
├── 자수 옵션 (선택사항)
├── 납기 / 예산 / 결제 방식
└── 추가 요청

견적 진행 (Quote Process)
   요청 → 매니저배정 → 견적서발송 → 자수시안 → 계약결제 → 제작납품
   (현재)  (2시간내)    (1~2일)     (2~3일)   (협의)    (5~14일)

단체 주문 (Bulk Order)
├── 일반 주문과 별도 시스템
├── 분할 배송 가능
├── 세금계산서 자동 발행
└── 신용 거래 (협의)
```

## 3. 데이터 흐름 (주요 시나리오)

### 시나리오 A: 일반 상품 + 자수 추가 구매

```
1. 사용자 → 상품 상세 페이지
2. [클라이언트] 상품 옵션 선택 (색상/사이즈)
3. [클라이언트] 자수 토글 ON
4. [클라이언트] 자수 종류/위치/내용 선택
5. [클라이언트] 가격 미리보기 (참고용)
6. 사용자 → "장바구니" 또는 "바로 구매"
7. [서버] 가격 재계산 (★ 클라이언트 가격 무시)
8. [서버] 재고 확인
9. 결제 페이지 → 결제 수단 선택
10. [서버] PG 호출 → 결제 승인
11. [서버] 주문 + 자수 시안 생성 (DRAFT 상태)
12. [서버] 디자이너에게 알림 (Slack/이메일)
13. 결제 완료 페이지 → 카톡 채널 추가 안내
14. (외부) 디자이너 → 카톡으로 시안 전송 → 고객 확정
15. [서버] 시안 확정 → 자수 작업 시작 → 출고
```

### 시나리오 B: 단체주문 견적 → 계약

```
1. 사용자 → 단체주문 견적 폼 (`/bulk-order`)
2. [클라이언트] 회사 정보, 사이즈별 수량, 자수 옵션 입력
3. [서버] 견적 요청 저장 (`quote_requests` 테이블)
4. [서버] 매니저에게 배정 알림
5. [내부] 매니저 → 견적서 작성
6. (외부) 견적서 메일/카톡 발송
7. [클라이언트] 고객 확인 → 계약 진행
8. [서버] 단체 주문 생성 (`bulk_orders` 테이블)
9. (생산) 자수 시안 → 시안 확정 → 생산 → 분할 납품
10. [서버] 세금계산서 자동 발행
```

## 4. 주요 비기능 요구사항 (NFR)

| 항목 | 목표 |
|------|------|
| **응답 시간** | 메인 페이지 < 1.5s (LCP) |
| **가용성** | 99.9% (월 다운타임 43분 이내) |
| **결제 트랜잭션** | 결제 승인 < 5s |
| **이미지 로딩** | WebP/AVIF 자동 변환, 지연 로딩 |
| **모바일 최적화** | Lighthouse 모바일 90+ 목표 |
| **SEO** | 모든 상품 페이지 SSR, 구조화 데이터 (Schema.org) |
| **보안** | OWASP Top 10 대응, PCI DSS 인지 |
| **검색** | 상품 검색 < 500ms (PostgreSQL 풀텍스트 또는 추후 ES) |

## 5. 보안 / 규정 요구사항

### 5.1 한국 법규
- ✅ **통신판매업 신고** (시 / 군 / 구청)
- ✅ **개인정보 처리방침** (개인정보보호법)
- ✅ **전자상거래법** 청약 철회 안내
- ✅ **에스크로 / 안전결제** 지원 (10만원 이상)
- ✅ **세금계산서 발행** 시스템 (법인 결제)
- ✅ **KCs 인증 정보** 명시 (산업안전보건법)

### 5.2 데이터 보호
- 비밀번호: bcrypt 또는 argon2 (절대 평문 금지)
- 카드 정보: PG사에 위임 (자체 저장 금지, PCI DSS 위반 방지)
- 사업자번호: 암호화 저장 (PII)
- 주민등록번호: 절대 수집 금지
- 로그: 결제/주문 정보 마스킹

### 5.3 인프라
- HTTPS 강제 (HSTS)
- CSP 헤더 적용
- Rate Limiting (API)
- DDoS 방어 (CDN 레이어)

## 6. 외부 서비스 의존성

| 서비스 | 용도 | 대안 |
|--------|------|------|
| **PG사** | 결제 | KG이니시스 / 토스페이먼츠 / 나이스페이 |
| **카카오톡 채널** | 자수 시안 전송, CS | 알림톡 API |
| **이미지 CDN** | 상품/자수 이미지 | Cloudinary / Vercel Blob / S3+CloudFront |
| **우편번호** | 주소 검색 | 카카오 주소 / 다음 우편번호 |
| **SMS** | 인증, 알림 | 알리고 / 솔라피 |
| **이메일** | 거래 알림, 마케팅 | Resend / SendGrid |
| **알림** | 내부 알림 | Slack Webhook |

## 7. 모니터링 / 운영

### 필수 모니터링
- **에러 추적**: Sentry
- **성능 모니터링**: Vercel Analytics 또는 New Relic
- **로그 집계**: Logtail / Datadog
- **알림**: Slack / Discord

### 핵심 메트릭
- 주문 성공률 / 결제 실패율
- 자수 시안 작업 평균 시간
- 단체주문 견적 응답 시간 (SLA: 2시간)
- 페이지별 LCP / CLS / INP
