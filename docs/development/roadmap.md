# 개발 로드맵 (Roadmap)

> 무료 개발자가 어느 순서로 작업해야 하는지 명확하게.
> 각 마일스톤은 **검수 가능한 결과물**을 가져야 함.

## 전체 일정 (개발자 1명 기준)

```
Phase 0: 셋업           (1주)
Phase 1: 인증 + 회원     (1주)
Phase 2: 상품 카탈로그   (2주)
Phase 3: 장바구니 + 결제 (2주) ⭐
Phase 4: 자수 시스템     (3주) ⭐
Phase 5: 단체주문 (B2B) (2주) ⭐
Phase 6: 마이페이지     (1주)
Phase 7: 정적 페이지    (1주)
Phase 8: 관리자 (간이)  (1주)
Phase 9: QA + 출시 준비 (2주)
─────────────────────────────
총 약 16주 (4개월)
```

⚠️ 무료 개발자는 시간 압박이 적을 수 있어 더 길어질 수 있음. 위 일정은 풀타임 기준.

## 우선순위 변동 시 대응

만약 일정이 부족하면 **줄일 수 있는 영역**:

```
[ ] 관리자 화면 (Phase 8) - Prisma Studio 로 임시 대체 가능
[ ] 정적 페이지 일부 (회사 소개 등) - 단순 HTML 로 대체 가능
[ ] E2E 테스트 일부 - 단위 테스트만 우선
[ ] 일부 결제 수단 (가상계좌 등) - 카드 우선
```

**절대 줄일 수 없는 영역**:

```
[X] 자수 시스템 - 사업 핵심
[X] 단체주문 - 매출의 70% 이상
[X] 결제 안전성 - 사고 시 신뢰 추락
[X] 모바일 반응형 - 사용자 70% 모바일
```

## 참조 우선순위

작업 시작 전 항상 확인:

1. `CLAUDE.md` — 프로젝트 메모리
2. `docs/domain/business-rules.md` — 비즈니스 규칙
