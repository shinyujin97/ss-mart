# 작업 로그 2026-06-13

## 사이트 전체 모바일 반응형 대응 (오케스트레이션)

### 배경
- 모바일로 접속하는 고객이 생겼는데, 사이트 전체가 데스크톱 전용으로만 짜여 있어 모바일에서 레이아웃이 깨짐.
- 진단: 99개 tsx 파일 전체에서 반응형 breakpoint(`sm:`/`md:`/`lg:`) 사용이 0회. 고정폭(`max-w-[1340px]`, 고정 grid, 햄버거 메뉴 없음)이 원인.

### 방식 — 멀티에이전트 오케스트레이션 (Workflow)
1. **본부(셸)**: 전역 헤더/네비/푸터를 먼저 모바일화하면서 반응형 컨벤션 확정 → 하위 작업조에 하달
2. **병렬 작업조 ×5**: 홈 / 상품·카탈로그 / 자수 / 마이페이지 / 안내·폼 — 겹치지 않는 파일 그룹 동시 작업
3. **검수 ×2**: typecheck + 비반응형 패턴 감사

### 확정된 반응형 컨벤션
- 주 분기 `md`(768px) 단일 기준, 그리드 미세조정에만 sm/lg
- 컨테이너 패딩 `px-4 md:px-6`, `max-w-[1340px] mx-auto` 유지
- "데스크톱 그대로 보존(`hidden md:flex`) + 모바일 대체 UI(`md:hidden`)" 방식
- z-index 계층: FloatingCTA(50) < 드로어 오버레이(60) < 드로어 패널(70)
- viewport 메타: `src/app/layout.tsx`에 `export const viewport` 추가

### 주요 변경
- **셸**: `MobileMenu.tsx` 신설(좌측 슬라이드 드로어 햄버거, body 스크롤락, usePathname 자동 닫힘). Header/Navigation/SearchBar/Footer/FloatingCTA/layout 반응형화. CategoryDropdown(고정폭 mega-menu)은 모바일에서 미렌더.
- **홈**: 히어로 3컬럼→세로 스택, BestCarousel matchMedia 기반 모바일 2개/데스크톱 4개, 브랜드 로고 5→3컬럼.
- **상품·카탈로그**: 상품상세 2단→세로 스택, CategoryFilter 모바일 접이식, 상품 그리드 2/3/4컬럼.
- **자수**: PositionShowcase 세로 스택, ProcessFlow/Steps 가로 스크롤 보존, 시뮬레이터 캔버스 위/옵션 아래, QuoteRequestModal 모바일 풀스크린.
- **마이페이지**: 사이드바→상단 가로 스크롤 탭, 표→카드형 세로 스택, 폼 라벨 1단화.
- **안내·폼**: about/support/login/signup/bulk-order 폼 1단 스택, 공지 테이블 모바일 카드형, 모달 풀폭화.

### 결과
- 총 63개 파일 변경(셸 7 + 페이지 56), MobileMenu.tsx 1개 신설
- `npm run typecheck` 통과(에러 0)
- 감사 지적 2건(brands/[slug] 헤더 비좁음, ProductImageGallery 썸네일 터치타깃) 직접 보정 완료
- 디자인 토큰/직각/폰트/카탈로그 전용 모드 모두 보존, 로직/props/링크/서버액션 무변경

### 남은 확인 (권장)

## 🚨 이미지 전체 깨짐 — Supabase 한도 초과 → R2 마이그레이션 (긴급)

### 원인
- 사이트 전체 상품 이미지가 깨짐. 원인은 코드가 아니라 **Supabase 스토리지가 무료 한도 초과로 차단(HTTP 402)**.
  - 응답: `Service restricted: exceed_egress_quota, exceed_storage_size_quota`
- DB의 ProductImage 7,869개가 100% supabase URL을 가리키고 있었음.
- R2로 이미지 파일은 일부 올렸지만 **DB URL 교체를 한 번도 안 돌린 상태**였음.

### 조치 (1단계 — 완료)
- `scripts/migrate-images-to-r2.ts` 작성: R2 공개 URL 존재 확인 후, 확정된 것만 DB url을 `supabase.co` → `pub-...r2.dev`로 교체.
- 결과: **6,136개(78%) 교체 완료**. R2에 존재 확인된 것만 바꿔 죽은 주소 위험 0.
- 이 DB는 프로덕션(Vercel)도 공유 → 배포 없이 운영 사이트도 즉시 복구됨.

### 남은 작업 (2단계 — R2 쓰기 자격증명 필요)
- 미복구 1,733개 = aceuniform 1,236 + tbuc 335 + ilteru 54 + flat 108
- 원본 소스: `aceuniform-scraped.json`, `tbuc-scraped.json`(+`sync-tbuc-images.ts`), `ilteru-scraped.json`
- flat 108개는 로컬/R2 모두 원본 없음 → 개별 소싱 필요(소수)
- ilteru 54개는 삭제된 브랜드(5/25) 잔존 레코드 → 정리 여부 결정 필요
- **블로커**: R2 자격증명(CLOUDFLARE_ACCOUNT_ID / R2_ACCESS_KEY_ID / R2_SECRET_ACCESS_KEY)이 `.env`에 없음
