─ SECTION 03 / EMBROIDERY VS PUNCHING ─

자수 / 펀칭 차이가 무엇일까?

DEFINITION / 01

자수

컴퓨터 자수란 원하는 이미지를 캐드프로그램으로 펀칭작업(실선을 짓는 과정)을 한 뒤 컴퓨터자수기계에 옷에 직접 새기는 과정을 말합니다.

캐드프로그램 좌표에 입력된 이미지를 컴퓨터자수기계가 인식하여 mm이내의 차이까지 초정밀로 구현해 냅니다. 대량생산에 적합하며 가장 내구성이 뛰어난 고품질 인쇄방식입니다.

DEFINITION / 02

펀칭

컴퓨터 자수 작업을 할 때, 작업하고자 하는 이미지나 로고 디자인의 실 색상, 침수를 컴퓨터자수기계에 입력시켜야 하는 과정이 있습니다.

컴퓨터캐드프로그램을 이용해 위 과정들이 이루어지며 이를 "펀칭"이라 합니다.

SECTION / 04
자수 / 마킹 종류
에스에스종합상사에서 가능한 자수 / 마킹 방식 7가지
TYPE / 01
컴퓨터 자수
원단에 직접 자수를 놓는 방식으로 입체적이고 견뢰도가 높아 많은 분들이 선호하는 자수방식입니다.
TYPE / 02
패치 자수
원단에 직접 자수를 놓는 방식이 아닌 다른 원단에 자수를 새긴 후 오버로크로 부착하는 방식으로 거짐원에 적합합니다.
TYPE / 03
아플리케 자수
원단에 실로 박음질을 하여 퀄리티가 높고 선명한 인쇄방식입니다. 디자인의 입체감을 표현하기에 좋습니다.
TYPE / 04
보풀 자수
보풀로 입체감을 주는 방식으로 주로 학교/유니폼에 많이 사용되는 자수방식입니다. (세탁 횟수 한정)
TYPE / 05
손 자수
미싱기로 직접 수를 놓는 방식으로 견뢰도가 높고 단순한 이름 또는 별명 인쇄가 가능합니다.
TYPE / 06
실사 패치 자수
와펜대두리만 컴퓨터자수로 제작되며 실사 출력을 하여 와펜형태에 열기계로 누르는 방식으로 제작됩니다.
TYPE / 07
벨크로 패치 자수
컴퓨터 자수가 된 원단에 벨크로(찍찍이) 처리하여 탈부착 가능한 자수인쇄방식입니다.
TYPE / 08
캐릭터
맞춤 디자인
로고 없어도 OK
저작권 안전 보장
캐릭터 디자인 (★ NEW)
로고가 없어도 전문 디자이너가 저작권에 안전한 맞춤 캐릭터를 제작해드립니다. 회사 정체성을 살린 유니크한 자수 디자인.
▲ RECOMMENDED

에스에스종합상사 추천 자수 인쇄 방법

01 RANK
컴퓨터 자수
직자수로도 불리며 가장 많이 사용하는 자수인쇄방법입니다. 원단에 직접 자수를 놓는 방식으로 깔끔하며 고급스럽습니다. 결과물이 입체적이고 견뢰도가 높아 오래 입어도 떨어지지 않습니다.
주의 / 레이어링되어 있는 펀칭작업이 있어 비용 면에서 대량작업에 적합하며 스판재질의 옷에는 추가가 불가능합니다.
02 RANK
패치 자수
옷에 직접적으로 인쇄하는 방식이 아닌 다른원단에 자수를 새긴 후 이를 오버로크로 부착하는 인쇄방법으로 주로 거울원에 많이 사용됩니다.
주의 / 옷에 부착하는 공정 때문에 컴퓨터자수 대비 추가 요금이 발생합니다.
03 RANK
캐릭터 맞춤 디자인 ★ NEW
로고가 없는 회사도 전문 디자이너가 저작권에 안전한 캐릭터를 제작해드립니다. 회사의 분위기, 직군, 컬러를 반영한 유니크한 디자인으로 차별화된 작업복을 만들어드립니다.
주의 / 디자인 시안 제작에 1~2일이 소요되며, 시안 확정 후 자수 작업이 진행됩니다.
