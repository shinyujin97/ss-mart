Q
자수 · 마킹
자수 작업은 얼마나 걸리나요?
+
A
자수 작업 일정은 다음과 같습니다.
  • 1~10벌 (개인 주문) ─ 결제 후 디자이너 시안 검수 (24시간 내) → 시안 확정 후 3~5영업일 내 작업 완료 / 배송
  • 10~99벌 ─ 시안 확정 후 5~7영업일
  • 100벌 이상 (단체주문) ─ 시안 확정 후 7~14영업일 / 사이즈 / 색상 다양성에 따라 변동
긴급 작업이 필요하시면 1588-0000으로 연락 주시면 협의 가능합니다.
Q
자수 · 마킹
자수 시안은 결제 전에 확인 가능한가요?
+
A
네, 두 가지 방법으로 확인 가능합니다. 시뮬레이터에서 직접 시안을 만들어 결제 전에 미리 보실 수 있고, 결제 후에는 전문 디자이너가 카톡(@ssmart)으로 시안을 전송해 드립니다. 시안 확정 전까지 무료로 무제한 수정이 가능합니다.
Q
자수 · 마킹
캐릭터 디자인도 가능한가요? 저작권 문제는 없나요?
+
A
네, 가능합니다. 다만 저작권 안전을 위해 디즈니, 마블, 인기 캐릭터 등 기존 IP는 사용할 수 없고, 고객사 자체 캐릭터 또는 저희가 새로 디자인하는 오리지널 캐릭터로 진행됩니다. 자체 캐릭터가 없는 경우, 저희 디자이너가 컨셉 설명을 듣고 오리지널 디자인을 무료 제공해드립니다.
Q
단체주문
100벌 단체주문 가능한가요? 가격 견적은 어떻게 받나요?
+
A
네, 100벌 이상 단체주문 시 최대 30% 추가 할인이 적용됩니다. 자수 / 마킹 작업도 무료로 포함됩니다. 견적 신청은 두 가지 방법으로 가능합니다.
  • 웹사이트 단체주문 견적 페이지에서 폼 작성 → 1~2영업일 내 회신
  • 전화 1588-0000으로 직접 상담 → 2시간 이내 매니저 배정
전담 매니저가 시안부터 납품까지 1:1로 책임집니다.
Q
주문 · 결제
세금계산서 발행 가능한가요?
+
A
네, 법인 / 개인사업자 회원은 결제 시 "법인 / 세금계산서" 결제 수단을 선택하시면 자동으로 발행됩니다. 일반 회원도 마이페이지 → 세금계산서 메뉴에서 별도 신청 가능합니다. 발행 후에는 이메일로 즉시 전송되며, 출력본도 별도 요청 가능합니다.
Q
배송
배송비는 얼마이고, 언제 도착하나요?
+
A
전 상품 무료 배송입니다 (제주 / 도서산간 추가비 없음). 일반 상품은 평일 14시 이전 결제 시 당일 출고 → 1~2일 내 도착이며, 자수 / 마킹 추가 상품은 시안 확정 후 5~7일이 소요됩니다.
Q
교환 · 환불
자수 작업된 상품도 교환 / 환불 가능한가요?
+
A
자수 / 맞춤 제작 상품은 단순 변심에 의한 교환 / 환불이 어렵습니다 (전자상거래법상 맞춤 제작 상품 제외 조항). 단, 제품 불량, 오배송, 자수 작업 불량의 경우 100% 무료 교환 / 환불이 가능합니다. 사진 첨부하여 1:1 문의로 접수해주세요.
Q
계정 · 멤버십
신규 가입 시 어떤 혜택이 있나요?
+
A
신규 가입 시 다음 혜택이 즉시 지급됩니다.
  • 2,000P 즉시 적립 ─ 가입 완료 즉시
  • 10% 첫 구매 쿠폰 ─ 최대 5만원 할인
  • 무료 자수 시안 1회 ─ 디자이너 직접 작업
  • 생일 축하 쿠폰 5,000원 ─ 매년 자동 발급
  • 단체주문 30% 할인 ─ 100벌 이상 시
